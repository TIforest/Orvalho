Pronto para a próxima pausa?

  1. Baixe e execute o instalador.
  2. Abra o Orvalho e escolha seu intervalo.
  3. Clique em Iniciar. Se quiser, marque Iniciar com o Windows.
Como funcionam as atualizações?

A partir da versão 1.1.2, o Orvalho consulta novas versões ao abrir e a cada seis horas enquanto estiver em execução. Quando encontra uma atualização válida, baixa, fecha, instala e reabre automaticamente, preservando o intervalo e retomando a contagem. Sem internet, continua funcionando e tenta novamente depois.

Quem usa a versão 1.0.0 precisa instalar esta versão uma vez para passar a receber as próximas atualizações. O download é hospedado no GitHub Releases.

Preciso instalar Java ou criar uma conta?

Não. O instalador inclui o Java necessário, e o aplicativo funciona sem cadastro. Seu intervalo fica salvo no computador. O acesso à internet é usado para consultar e baixar atualizações.
