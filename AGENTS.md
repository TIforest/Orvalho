# Preferências do projeto

- Manter a versão do aplicativo em **1.2.22**, autorizada pelo usuário para publicação. Alterar o número de versão somente quando o usuário pedir explicitamente; não incrementar automaticamente ao implementar ou gerar instaladores.
- O tema original azul é o padrão. Outubro Rosa deve ser escolhido pelo usuário nas configurações, e a escolha deve persistir entre reinícios.
- Seguir o padrão de cores, botões e formas do aplicativo em novas telas e alterações.
